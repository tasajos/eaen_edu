📊

Evaluación Catedrático (90%)

El docente configura libremente los tipos de evaluación y sus pesos (los pesos deben sumar 100%). Puede usar el sistema clásico o el sistema dimensional SHD.

  • Configuración flexible: Examen, Tarea, Práctica, etc.
  • Sistema SHD: Saber 30% · Hacer 40% · Decidir 20%
  • 18 indicadores SHD organizados por sección
  • Bloqueo de notas para evitar modificaciones
🤝

Evaluación Facilitador (2.5%)

El facilitador del grupo evalúa a cada cursante con 4 criterios en escala 1-10. El promedio se convierte a puntos sobre 2.5.

  • Criterio 1: Aporta información al grupo
  • Criterio 2: Aprecia los hechos
  • Criterio 3: Decide con acierto
  • Criterio 4: Sostiene sus criterios
👥

Evaluación entre Cursantes (5%)

Cada cursante evalúa a sus compañeros durante un período habilitado por el jefe. El promedio recibido compone el 5% de la nota.

  • 4 indicadores de conducta y desempeño
  • Períodos habilitados/deshabilitados por jefe
  • Resultados agregados con promedio por indicador
  • Evaluación anónima entre pares
⚖️

Disciplina (2.5%)

Los méritos suman y los deméritos restan puntos del saldo disciplinario. El saldo neto (mínimo 0) aporta hasta 2.5 puntos a la nota.

  • 10 tipos de méritos/deméritos pre-definidos
  • Puntos: 1 a 3 por incidencia
  • Registro con fecha y descripción
  • Historial completo por cursante

Flujos Operativos

Los principales flujos de trabajo del sistema organizados por actor.

🎓
Flujo de Gestión de Curso
1. Jefe crea el curso
2. Asigna participantes (cursantes)
3. Asigna responsabilidades (jefe, facilitador, encargado)
4. Crea materias y asigna docentes
5. Configura evaluaciones por materia
6. Activa períodos institucionales
👨‍🏫
Flujo del Docente (por materia)
1. Crea y envía planificación de materia
2. Registra asistencia por fecha
3. Crea tareas con fecha límite
4. Califica entregas de cursantes
5. Registra notas (catedrático / SHD)
6. Bloquea calificaciones al finalizar
🎒
Flujo del Cursante
1. Ve horario y materias de su curso
2. Descarga y entrega tareas (.docx)
3. Evalúa a pares y docente (período activo)
4. Consulta Mi Desempeño (nota integrada)
5. Consulta Mi Disciplina e historial
6. Revisa estado de pagos y mora
📋
Flujo de Evaluación Institucional
1. Jefe habilita período de evaluación
2. Sistema genera respuestas pendientes
3. Cursante evalúa pares (4 indicadores)
4. Cursante evalúa docente (13 indicadores)
5. Jefe desactiva período
6. Jefe consulta resultados agregados

Arquitectura Técnica

Stack moderno full-stack con servidor monolítico Express y cliente React/Vite. Deploy en cPanel con LiteSpeed.

🖥️ Frontend

React 19 + Vite
React Router v7
Fetch nativo + interceptor JWT
localStorage (sesión + token)
CSS inline + módulos CSS

🔧 Backend

Node.js + Express 5
JWT (jsonwebtoken, 8h)
bcryptjs (passwords)
multer (uploads .docx)
Sirve frontend/dist estático

🗄️ Datos e Infra

MariaDB 10.4 (mysql2)
cPanel hosting
LiteSpeed Web Server
siseaen.cbba.chakuy.online
GitHub (repositorio)
🔐

Seguridad

  • JWT Bearer token en todas las rutas API
  • Contraseñas con bcrypt (salt 10)
  • Migración automática de passwords legacy
  • Rutas públicas: solo /health y /auth/login
📁

Almacenamiento

  • Archivos .docx en /uploads/tareas/
  • Nombres aleatorios generados por multer
  • Límite 5 MB por entrega
  • Eliminación automática al resetear entrega
🚀

Deploy

  • Frontend compilado con Vite (dist/)
  • Servido estáticamente por el backend
  • Deploy manual vía Git pull + npm install
  • Restart vía cPanel Node.js Selector
